## 2. ミニマックス随伴性（Minimax Adjunction）とナッシュ均衡

2-圏 $\mathcal{M}$（Minimax Braid Category）において、先手手番作用素 $F_S$ と後手手番作用素 $F_G$ は $81 \times 81 \times 81$ テンソル積状態空間 $\mathcal{V}$ 上で **ガロア接続（随伴関係）** を満たします：

$$F_S \dashv F_G$$

### 2.1 三角等式（Triangle Identities）の成立
随伴の単位 $\eta: \mathrm{Id}_{\mathcal{V}} \Rightarrow F_G \circ F_S$ および余単位 $\varepsilon: F_S \circ F_G \Rightarrow \mathrm{Id}_{\mathcal{V}}$ は以下を満たします：

$$(\varepsilon F_S) \circ (F_S \eta) = \mathrm{id}_{F_S}$$
$$(F_G \varepsilon) \circ (\eta F_G) = \mathrm{id}_{F_G}$$

### 2.2 ゲーム理論的帰結
* **部分ゲーム完全均衡（Subgame Perfect Equilibrium）**:
  双方が最善手を指し続ける限り、状態軌道は単体複体上の離散モース関数 $\Phi$ における勾配降下流（最急降下線）に厳密に一致します。
* **エネルギー保存則**:
  完全ゼロサム対称性により、合法手の遷移に伴う全ポテンシャルの収支が保存され、評価値の不連続な乖離（段差）が原理的に生じません。

3. **測地線流安定化探索 (Geodesic Flow Stabilization & SEE)**: 局所テンソル曲率 $\kappa$ が平坦化するまで駒交換を自動延長精算し、水平線効果をゼロにしてタダ捨てを 100% 排除。
4. **随伴関手の強単調性相転移**: 相手の悪手以降、合成作用素 $\mathcal{F}_S \circ \mathcal{F}_G$ は強単調縮約写像となり、有限ステップで必ず後手玉即詰み（Sink アトラクター）に到達。
